# SviBlox Privacy Policy

This repository hosts the privacy policy for the **SviBlox** browser extension, served via GitHub Pages:

➡️ **https://l0rrdi.github.io/sviblox-privacy/**

That URL is the one linked from the Chrome Web Store listing.

## Files

- [`index.html`](index.html) — the published page (served by GitHub Pages).
- [`PRIVACY_POLICY.md`](PRIVACY_POLICY.md) — the same policy in Markdown.

When the policy changes, update both files and bump the effective date.
